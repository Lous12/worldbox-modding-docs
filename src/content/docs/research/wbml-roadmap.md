## Re-open rule

Do not start another systematic WBML version for ordinary mod development. Re-open the lab only when WorldBox/NML changes or a direct contradiction to the frozen baseline is found. Then start with a baseline diff and re-test changed areas instead of blindly repeating every suite.

Capability recipes, a shared WorldBox Modding API and Mod Studio are product/tooling work built **from** the evidence; they are not required to keep the research campaign open.
