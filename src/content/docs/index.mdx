## One fact, four useful layers

The WBML knowledge base is now published as one connected chain. Use only as much depth as you need:

<div class="quick-link-row" aria-label="Knowledge layers">
  <a href="./quick/"><span>QUICK</span>Fast entity/task answer</a>
  <a href="./api/"><span>DEEP</span>Signature + provenance + caveat</a>
  <a href="./research/"><span>WBML</span>Experiment + rejected assumptions</a>
  <a href="./ai/wbml-machine-data/"><span>DATA</span>Canonical JSON for tools/AI</a>
</div>

Quick Docs may simplify the route, but they never override Detailed Docs or canonical machine evidence. The current integrated batch covers **WBML 0.2.0 through 0.9.0; WBML 1.0 freezes the current-runtime baseline**.
