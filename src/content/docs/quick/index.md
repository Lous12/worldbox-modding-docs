Quick Docs are the **convenience layer**. Use them when you need the shortest safe answer first.

For every non-trivial claim, the path is:

```text
Quick Docs → Detailed API/reference → WBML Research → canonical machine data
```

Quick Docs never override a caveat from the deeper layers. If a topic is not covered by canonical evidence, it is marked **research-needed** instead of being guessed.
