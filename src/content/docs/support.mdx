# Support WorldBox Modding Docs

WorldBox Modding Docs is **free and open**. Documentation, research results and troubleshooting material are not placed behind donations.

Support is completely optional. If the project saves you development time, a donation helps justify spending more time on:

- controlled WorldBox / NeoModLoader experiments;
- Modding Lab probes;
- compatibility testing after game or loader updates;
- reproducing difficult bugs;
- maintaining English and Russian documentation;
- AI-friendly structured references and examples.

## No paid documentation tier

The goal is to build a public knowledge base that other modders — and coding assistants — can reuse.

Donating does **not** unlock hidden API documentation or a private version of the site.

The best non-financial support is also simple: link a useful page to another modder, report outdated behavior after a WorldBox update, or contribute a reproducible test result.
