Quick Docs — это **удобный слой**, а не замена технической документации. Открывай его, когда сначала нужен самый короткий безопасный ответ.

Для любого нетривиального утверждения путь такой:

```text
Quick Docs → подробный API/справочник → WBML Research → canonical machine data
```

Quick Docs не имеют права стирать caveat из глубоких слоёв. Если canonical evidence нет, пишем **research-needed**, а не угадываем.

Текущий основной runtime scope новых WorldBox-страниц: **WorldBox 0.51.2 build 719 · Unity 2022.3.60f1 · NeoModLoader 1.2.0.1**.
