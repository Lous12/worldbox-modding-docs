# Поддержать WorldBox Modding Docs

WorldBox Modding Docs остаётся **бесплатной и открытой**. Документация, результаты исследований и troubleshooting не прячутся за донатами.

Поддержка полностью добровольная. Если проект сэкономил тебе время разработки, донат помогает оправдать ещё больше времени на:

- контролируемые эксперименты WorldBox / NeoModLoader;
- probes в Modding Lab;
- compatibility-тесты после обновлений игры или загрузчика;
- воспроизведение сложных багов;
- поддержку русской и английской документации;
- структурированные reference и примеры для ИИ.

## Никакой платной версии документации

Цель проекта — публичная база знаний, которой смогут пользоваться другие моддеры и coding assistants.

Донат **не открывает** скрытый API reference или приватную версию сайта.

Поддержать проект без денег тоже легко: отправить полезную страницу другому моддеру, сообщить об устаревшем поведении после обновления WorldBox или принести воспроизводимый результат теста.
