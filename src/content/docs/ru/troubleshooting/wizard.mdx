# Помощник по ошибкам

Когда что-то ломается, начинай с **симптома**, а не с догадки о причине. Помощник специально не притворяется, что способен автоматически диагностировать любой мод.

<TroubleshooterWizard lang="ru" />

Если помощник не сузил проблему, используй [Анализатор Player.log](../../workbench/log-analyzer/) и оставь самый маленький воспроизводимый тест, который можешь получить.
