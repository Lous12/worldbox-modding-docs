# `NullReferenceException`

`NullReferenceException` означает, что код попытался использовать ссылку, равную `null`. Само исключение **не доказывает**, какой именно объект был null и почему.

## Порядок расследования

1. Найди первый релевантный `NullReferenceException` и строки рядом.
2. Найди первый метод из своего мода или точный vanilla component, который ты трогал.
3. Проверь, должен ли нужный объект вообще существовать **на этом этапе lifecycle**.
4. Если падение появилось после UI clone, сначала проверь скопированные `MonoBehaviour` / `EventTrigger`, а не раскидывай null-check по всему коду.
5. Сведи воспроизведение к минимальному пути и логируй ссылки прямо перед падающим вызовом.

TerraForge уже ловил такой случай из-за `Awake()` скопированного vanilla UI behavior. См. [Безопаснее клонировать vanilla UI](../../recipes/safe-ui-clone/).
