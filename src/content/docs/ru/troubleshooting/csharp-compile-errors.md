# Ошибки компиляции C# в NeoModLoader

Если в `Player.log` есть, например:

```text
error CS0103
error CS0117
error CS0246
```

это **compile-time** проблема. Сначала исправь её, и только потом отлаживай runtime.

## Порядок

1. Найди **первую** compiler error в блоке компиляции мода.
2. Запиши `CSxxxx` и файл/строку, если они указаны.
3. Исправь самую раннюю ошибку: одна ошибка типов/синтаксиса может породить много вторичных.
4. Проверь, существует ли вызываемый API/member именно в версии, которая реально загрузилась в игре.
5. Запусти снова и убедись, что группа compiler errors исчезла.

## Частые категории

- `CS0103` — имя недоступно в текущем контексте.
- `CS0117` / `CS1061` — у типа/объекта нет вызываемого member.
- `CS0246` — тип или namespace не найден.
- syntax codes — часто создают каскад; начинай с первой ошибки.

Это подсказки для маршрута, а не замена полного текста компилятора.

Для PoliticalWorldAPI сверяйся с [API Explorer](../../workbench/api-explorer/) и текущим runtime, а не с памятью о другой версии.
