## Что умеет версия 2.0

Она вытаскивает build WorldBox, версию NeoModLoader, PoliticalWorldAPI и загруженные моды, а затем группирует узнаваемые сигналы:

- C# compiler errors `CSxxxx`;
- `StackOverflowException` и `NullReferenceException`;
- Event Bus callback failures;
- ошибки создания NML listener;
- Political World `WARN` / `ERROR` diagnostics;
- Harmony/patching сигналы;
- missing localization;
- частый network/TLS и fallback-library шум.

Для каждой распознанной группы Analyzer предлагает ближайший подходящий гайд или reference.

## Важная граница

Это **первичная диагностика**, а не автоматический root-cause oracle. Сигнатура доказывает наличие конкретной ошибки/исключения, но обычно не доказывает причину без контекста и воспроизведения.
