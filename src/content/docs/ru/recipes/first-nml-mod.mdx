# Первый минимальный NML-мод

<span class="doc-status">✅ Working WBML structure</span>
<span class="doc-status">WorldBox 0.51.2 build 719</span>
<span class="doc-status">NeoModLoader 1.2.0.1</span>

## Цель

Заставить NeoModLoader загрузить крошечный мод и вывести одну однозначную строку в `Player.log`.

Пока **не добавляй** UI, Harmony-патчи, сохранения и игровую логику. Сначала докажи, что каркас вообще загружается.

## 1. `mod.json`

Используй [генератор стартового мода](../../workbench/mod-generator/), если не хочешь писать manifest вручную.

Минимальная форма, которую использует рабочий генератор:

```json
{
  "name": "My First Mod",
  "GUID": "YourName.MyFirstMod",
  "author": "YourName",
  "version": "0.1.0",
  "description": "My First Mod",
  "targetGameBuild": 719,
  "Dependencies": [],
  "OptionalDependencies": [],
  "IncompatibleWith": []
}
```

Выбери GUID один раз и не меняй его после публикации.

## 2. `Main.cs`

```csharp
using NeoModLoader.api;

namespace YourName.MyFirstMod
{
    public class Main : BasicMod<Main>
    {
        protected override void OnModLoad()
        {
            LogInfo("[My First Mod] Loaded");
        }
    }
}
```

## 3. Запусти игру и проверь `Player.log`

Этап готов, когда в логе есть твой точный marker:

```text
[My First Mod] Loaded
```

Если строки нет, **не отлаживай игровую механику**. Проблема всё ещё в загрузке, компиляции или manifest.

Открой [анализатор Player.log](../../workbench/log-analyzer/) или [гайд по ошибкам компиляции C#](../../troubleshooting/csharp-compile-errors/).

## Следующий шаг

Добавь **одну** механику из [библиотеки рецептов](../). Оставь рабочий load-marker, пока мод не станет стабильным.
