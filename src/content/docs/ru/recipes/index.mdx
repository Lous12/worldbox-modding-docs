# Рецепты

Начни с результата, который хочешь получить. Главные рецепты теперь имеют собственные короткие страницы: **минимальный код → ожидаемый результат → частая ошибка → граница доказательства → полная справка**.

<RecipeFinder lang="ru" />

## Как пользоваться

1. Выбери самую похожую задачу, даже если формулировка отличается.
2. Сначала заставь работать минимальную версию.
3. Прочитай ожидаемый результат и частые ошибки.
4. Только потом уходи в полный API/case study, если нужна глубина.
5. Если твой runtime ведёт себя иначе, сохрани `Player.log` и считай это вопросом совместимости, а не поводом угадывать.
