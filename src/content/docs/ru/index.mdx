## Один факт — четыре полезных слоя

Теперь WBML knowledge base публикуется одной связанной цепочкой. Открывай ровно столько глубины, сколько нужно:

<div class="quick-link-row" aria-label="Слои знаний">
  <a href="./quick/"><span>QUICK</span>Короткий ответ по entity/task</a>
  <a href="./api/"><span>DEEP</span>Signature + provenance + caveat</a>
  <a href="./research/"><span>WBML</span>Эксперимент + rejected assumptions</a>
  <a href="./ai/wbml-machine-data/"><span>DATA</span>Canonical JSON для tools/AI</a>
</div>

Quick Docs могут сокращать путь, но не имеют права спорить с Detailed Docs или canonical machine evidence. Текущий полностью интегрированный batch покрывает **WBML 0.2.0–0.9.0 + frozen 1.0 baseline**.
