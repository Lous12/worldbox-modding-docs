# Словарь новичка

Короткий словарь, чтобы читать остальную документацию без ощущения, что все вокруг разговаривают заклинаниями.

| Термин | Что это значит |
|---|---|
| **Mod / мод** | Код или контент, который загружается и меняет/расширяет игру. |
| **NML / NeoModLoader** | Mod loader, на котором основаны текущие гайды и эксперименты WBML. |
| **`mod.json`** | Метаданные мода и информация о зависимостях. |
| **`Main.cs`** | C# entry file, который используется в нашем минимальном стартовом каркасе. |
| **GUID / addon ID** | Стабильная строка-идентификатор. Не меняй её без причины после того, как от неё зависят опубликованные данные/контент. |
| **API** | Публичные функции/типы, которые одна система специально даёт использовать другой. |
| **Runtime** | То, что реально делает запущенная версия игры/мода, а не то, что обещает старый исходник или текст. |
| **Lifecycle** | Когда моды/миры/объекты создаются, загружаются, переиспользуются, заменяются или завершаются. |
| **Persistence** | Данные, которые должны пережить текущий момент в памяти — обычно save/load и restart. |
| **Player.log** | Основной текстовый лог, через который здесь проверяются compile, загрузка, версии, marker и exceptions. |
| **Marker** | Уникальная строка, которую ты сам пишешь в лог, чтобы доказать запуск конкретного куска кода. |
| **Exception** | Runtime-ошибка вроде `NullReferenceException` или `StackOverflowException`. |
| **Harmony patch** | Изменение/перехват методов во время runtime. Мощно, но сильнее зависит от версии, чем поддерживаемый API. |
| **Reflection** | Динамический поиск/доступ к типам и членам. Полезно для исследования, но тоже version-sensitive. |
| **Verified** | Поведение воспроизведено проектом в явно указанной границе теста. |
| **Observed** | Поведение увидели в runtime, но ещё недостаточно поняли/ограничили для полного Verified. |
| **SKIP** | Ветка теста не выполнялась; это **не** доказательство, что она работает. |

Если термин всё ещё непонятен — сначала смотри практический пример на странице, а уже потом глубокий reference.
