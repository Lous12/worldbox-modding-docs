## Чего этот чеклист не доказывает

Завершение означает, что **текущий каркас и одна выбранная механика** заработали в твоём окружении. Это не делает любой API version-independent и не отменяет evidence boundary на каждой странице рецепта/справочника.

Когда следующая задача зависит от версии, открывай [Матрицу совместимости](../../workbench/compatibility/).
