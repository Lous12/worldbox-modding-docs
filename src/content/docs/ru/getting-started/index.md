# Начать здесь

Тебе **не нужно** сначала учить весь API WorldBox. Первая цель намного меньше: заставить NeoModLoader увидеть мод, доказать, что он загрузился, и только потом добавить ровно одну механику.

<div class="friendly-callout friendly-callout-good"><strong>Цель этой страницы</strong><span>Дойти до состояния: «loader видит мой мод, и мой код реально запускается».</span></div>

## Шаг 1 — Убедись, что NeoModLoader работает

Запусти WorldBox с NeoModLoader. Если у тебя уже есть `Player.log`, открой [Анализатор Player.log](../workbench/log-analyzer/). В нормальной NML-сессии в логе должны быть строки NeoModLoader и загрузки модов.

<div class="done-when"><strong>Готово, когда:</strong> ты можешь найти активность NML в логе.</div>

Если NML вообще не видно, остановись здесь. Пока не копируй код PoliticalWorldAPI или Harmony — проблема находится раньше логики твоего мода.

## Шаг 2 — Создай самый маленький мод

Открой [Генератор стартового мода](../workbench/mod-generator/). Текущие WBML probes используют маленькую структуру вроде:

```text
MyMod/
├── mod.json
└── Main.cs
```

Генератор использует `BasicMod<Main>` и `OnModLoad()`, потому что такая форма реально компилировалась и загружалась в наших текущих runtime-экспериментах.

<div class="done-when"><strong>Готово, когда:</strong> у тебя есть маленькая папка мода без лишних систем.</div>

## Шаг 3 — Запусти его до добавления механик

Запусти игру. Проверь `Player.log`: там должно появиться имя твоего мода и простое сообщение `OnLoad` / `Loaded`.

Если мод не загружается, открой [Помощник по ошибкам](../troubleshooting/wizard/) вместо того, чтобы добавлять ещё код.

<div class="done-when"><strong>Готово, когда:</strong> лог доказывает, что твой собственный код запустился.</div>

## Шаг 4 — Добавь одну механику

Выбери **одну** маленькую цель в [Рецептах](../recipes/): сохранить значение, подписаться на событие, создать action, поработать с миром или разобрать конкретную ошибку.

Не добавляй одновременно UI + Harmony + persistence + events. Если сломается одна вещь, маленький тест намного проще понять.

## Шаг 5 — Проверь границу доказательства

Код может быть правильным для одного сочетания WorldBox / NML / API и измениться позже. Перед зависимостью от version-sensitive поведения открой [Матрицу совместимости](../workbench/compatibility/).

<div class="friendly-callout"><strong>Правило новичка</strong><span>Сначала заставь мод загрузиться. Потом заставь работать одну вещь. И только потом делай умно и сложно.</span></div>
