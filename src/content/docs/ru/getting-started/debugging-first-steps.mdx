# Отладка — первые проверки

Не начинай с случайного переписывания кода. Сначала определи, **что именно ты наблюдаешь**.

  <div><span>1</span><strong>C# compile error</strong><p>Используй точный код <code>CSxxxx</code> и сообщение. Сначала компиляция, потом runtime.</p><a href="../../troubleshooting/csharp-compile-errors/">Ошибки компиляции →</a></div>

## Сделай маленькое воспроизведение

Хороший reproduction содержит:

```text
точные версии игры / NML / зависимостей
минимальное нужное состояние мира/save
точные шаги
ожидаемый результат
фактический результат
релевантный кусок Player.log
```

По возможности убирай несвязанные системы. Если после удаления чего-то проблема исчезла — это тоже полезное evidence.

## Не каждая страшная строка — причина

Network/TLS и fallback-library сообщения могут встречаться рядом с проблемой и не быть её причиной. Анализатор отдельно помечает известный шум, но даже найденная сигнатура ещё не доказывает root cause.
