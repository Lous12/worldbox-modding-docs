# Temporary homepage icon concepts

The eight PNG files under `public/icons/home/` are temporary concept art for the practical UX redesign. They are intentionally stored behind stable filenames so they can later be redrawn by hand without touching the page markup.

Replace a file with a new transparent PNG using the same filename and the site will keep working:

- `start.png` — beginner / first mod
- `recipes.png` — recipes / how-to routes
- `ui.png` — UI / windows / buttons
- `persistence.png` — save data / persistence
- `political-world.png` — Political World addons
- `worldgen.png` — world / world generation
- `tools.png` — mod generator / developer tools
- `troubleshoot.png` — troubleshooting / broken mod

Recommended redraw target: square transparent canvas, strong silhouette, readable at 56–80 CSS pixels, no text inside the artwork. The website also uses short text badges such as `LOG`, `API`, and `VER` for utility tools so core navigation does not depend on emoji font coverage.
