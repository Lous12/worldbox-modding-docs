# WorldBox Modding Docs v0.2.0 — Workbench Release

`v0.2.0` is the first stable release of the practical Workbench redesign.

The site now has two layers that intentionally coexist:

1. **Practical layer for humans:** beginner routes, recipes, tools, troubleshooting and short explanations.
2. **Evidence layer:** API/reference pages, research, case studies, sanitized logs and explicit reliability labels.

## What a new modder gets

A visitor can start from a goal instead of an API name: make a first mod, save data, work with UI, inspect Political World, touch world generation, or diagnose a broken mod. The site routes them toward the shortest useful recipe or browser tool first.

## Browser tools in the stable baseline

- Player.log Analyzer 2.0
- Starter Mod Generator
- API Explorer
- Compatibility Matrix
- Recipe Finder / Recipe Library 2.0
- Symptom-first Troubleshooter
- Beginner first-mod progress checklist

The Player.log Analyzer and beginner progress state are local to the browser. The site does not need to upload a Player.log to a server to perform its current analysis.

## Evidence policy

The stable website release does not mean the underlying modding ecosystem is fully mapped. Runtime claims remain scoped to the tested versions and WBML experiments that support them. `Verified`, `Observed`, `Experimental`, `Inferred`, `Failed`, and `Outdated` keep their existing meanings.

Current documented Lab baseline remains WBML-0001 through WBML-0005. New runtime research resumes after the v0.2.0 site release.

## Language and project identity

English and Russian remain first-class site versions. The project keeps the epigraph `Какова цена свободы?`, the replaceable temporary artwork filenames, and optional DonationAlerts / DALink support links.

## Next research cycle

After v0.2.0, the normal loop is:

`WBML experiment → evidence → beginner explanation → reference/API update → AI-facing rule`

The next planned Lab area is NeoModLoader lifecycle research.
